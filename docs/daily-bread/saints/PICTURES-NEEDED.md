# الصور المطلوبة لقايمة القديسين

87 اسم. لكل اسم: صورة واضحة للشخص الصح، ومعاها **رابط الصفحة اللي جاية منها**، و**الرخصة أو شروط الاستخدام** لو مكتوبة.

- **القديسين القدامى:** أيقونة قبطية حديثة وملونة وواضحة (زي صورة العدرا اللي بعتها).
- **المعاصرين** (البابوات والأساقفة والآباء من القرن الـ٢٠ لحد دلوقتي): صورة فوتوغرافية حقيقية واضحة، أو أيقونة لو اتعملتله.
- **الاسم بالإنجليزي** للبحث في مواقع الصور.
