CHANGES — الدراسة ↔ النهائي

لكل شاشة: «الدراسة» (صور 2026-11-14، الفكرة والتجربة اللي اتعمدوا) جنب «النهائي» (W1)، وإيه اللي اتغير وليه. الفكرة والترتيب والقرارات الـ١٥ زي ما هي؛ اللي اتغير هو الشكل: بقى مبني على CSS الموقع الحقيقي والأدمن 8B نفسهم. الشاشات الجديدة اللي مكانتش في الدراسة مكتوب جنبها «جديدة».
